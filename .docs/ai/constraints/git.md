# Git 提交规范

## Commit 消息格式

格式为 `<类型>: <中文描述>`，类型用英文，描述用中文。

### 允许的类型

| 类型 | 说明 |
|------|------|
| feat | 新功能 |
| fix | 缺陷修复 |
| refactor | 重构 |
| docs | 文档 |
| test | 测试 |
| chore | 构建/工具 |
| perf | 性能优化 |
| ci | CI/CD |

### 示例

```
feat: 新增数据源手动同步功能
fix: 修复分类器空指针异常
refactor: 拆分查询零填充与前端接口层
```
